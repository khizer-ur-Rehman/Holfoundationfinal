# HOL Foundation - React.js Web Application

A complete, modern React.js + Vite application for HOL Foundation (House of Learning Foundation), empowering communities across Lyari, Karachi through education, healthcare, vocational training, and youth entrepreneurship.

## Features & Stack
- **Framework:** React 19 + Vite
- **Routing:** React Router v7 (`react-router-dom`) with clean direct URLs and fallback support
- **Smooth Scrolling & Animations:** Lenis smooth scrolling + GSAP ScrollTrigger
- **Pages Included:**
  - Home (`/`)
  - Our Work (`/our-work`)
  - Our Board (`/our-board`)
  - Our Journey (`/our-journey`)
  - Donate (`/donate` with live sponsorship calculator & bank accounts)
  - Contact (`/contact` with interactive inquiry form)
  - Careers (`/careers` with Jobs, Internships & Volunteering tabs)
  - News & Stories (`/news` with Instagram reel gallery)
  - Publications & Regulatory Orders (`/publications` with PDF downloads)
  - Interactive Annual Report (`/annual-report` with Heyzine Flipbook viewer)
  - GBSS Kara Bhai Karim Jee Campus (`/programs/hol-kb-campus`)
  - Lyari Entrepreneur Academy (`/programs/lyari-entrepreneur-academy`)
  - HOL Preschool (`/programs/hol-preschool`)
  - School Preparatory Program (`/programs/school-preparatory-program`)
- **Assets:** Complete original photography, icons, typography, and official UN Sustainable Development Goals wheel

## Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser at [http://localhost:3000](http://localhost:3000).

### 3. Build for Production
```bash
npm run build
```

### 4. Run Production Server
```bash
npm start
```
Runs the Express production server on port 3000.
